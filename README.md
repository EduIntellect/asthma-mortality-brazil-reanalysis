This repository scaffolds a reproducible reanalysis of asthma mortality trends in Brazil for 2014-2021 based on Brum et al. using SIM/DATASUS microdata. The project is structured to verify whether the reported mortality increase persists when the original methodology is followed as closely as possible. It also pre-defines two extensions on the same data: direct age-standardization and a focused 5-34 age-group analysis. Any required deviations are intended to be explicitly documented only when originally published resources are unavailable.
